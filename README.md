# BlankTrading — Company Website

A clean, dark, professional single-page website for **BlankTrading**, an
independent IT development company based in Germany, led by Leo Solomon.

## Structure

| File | Purpose |
|------|---------|
| `index.html` | Page markup and content |
| `styles.css` | Dark design system and layout (no framework) |
| `script.js`  | Mobile nav + footer year |

No build step, no dependencies. Open `index.html` in a browser, or serve it:

```bash
python -m http.server 8000
```

## Sections

Hero · Services · About · Contact · Footer with **Impressum** (legally required
in Germany).

## Before going live

Complete the **Impressum** with the full legal address and, if applicable, a
VAT ID (USt-IdNr.) — required under German law (§ 5 TMG). A placeholder
("Vollständige Anschrift auf Anfrage") is in place for now.
